## ✅ WHAT IS *NOT* A SEPARATE PATTERN (IMPORTANT CLARIFICATION)

These are **NOT independent patterns**, but combinations:

❌ “DP on array” → usually Kadane / prefix  
❌ “Stack + array” → monotonic stack  
❌ “Greedy DP” → greedy scan  
❌ “Math array problems” → edge cases, not patterns
